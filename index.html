내 자동매매 사이트 열기

한 번 등록한 접속 주소를 이 브라우저에서 기억합니다.

PC 연결 설정이 끝나면 발급된 주소를 등록하세요.

비밀번호는 연결된 사이트에서 입력하세요.

이 접속 페이지에서는 로그인이나 계좌 정보를 입력하지 않습니다.

01

PC 서버 실행

PC와 Docker가 켜져 있고 자동매매 사이트가 실행 중이어야 합니다.

02

개인 기기 연결

PC와 휴대폰의 Tailscale에 같은 계정으로 로그인하고 연결을 켜세요.

03

사이트 접속

위에 등록한 주소로 이동한 뒤 기존 사이트 비밀번호로 로그인하세요.

사이트가 열리지 않나요?

PC의 인터넷·Docker·사이트 실행 상태와 휴대폰의 Tailscale 연결을 확인하세요. PC가 꺼져 있거나 절전 상태이면 접속할 수 없습니다.

이 페이지는 서버 연결 상태를 검사하지 않습니다. 사이트를 열어 실제 응답을 확인하세요.
